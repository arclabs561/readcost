# Paper notes

One file per paper that readcost cites or tested an idea from. Each note
is written in our own words and says how much of the paper was read; it
records what readcost takes from the paper and what the full text
qualifies or contradicts relative to its abstract. Quotations are short
and marked. docs/research.md and docs/evaluation.md cite these papers;
this directory keeps the reading behind those citations.

File name: `firstauthor-year-keyword.md`, lowercase.

```markdown
# Title

Authors. Year. Venue. Link (arXiv, ACL Anthology, DOI).

Read: full | sections ... | abstract only (why: paywall, no PDF).

## Claim
## Method and data
## Results (numbers that matter)
## What the full text qualifies
## For readcost (used / tested / candidate / not applicable, and where)
## Open questions
```
