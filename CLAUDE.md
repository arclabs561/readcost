# Notes for coding agents

- Never add AI attribution to commits, pull requests, reviews, comments or
  files: no Co-Authored-By trailers, no Claude-Session trailers, no session
  links, no "Generated with" or "Generated by" lines. `.claude/settings.json`
  turns these off; the prose workflow fails a pull request that has them.
- Run `uv run pytest -q` and `uv run readcost check . --fail-on block` before
  committing, and `uv run readcost check README.md docs --fail-on advise`
  after changing documentation.
